HOW TO REVIEW WITHOUT HARDWARE: On the first screen, tap "Try demo mode — no table needed." This loads a built-in simulated sand table so you can explore the entire app — browse and run patterns, watch the live progress trace, build playlists, and adjust the LED controls — with no physical device required. No login or account is needed for any of this.

ABOUT THE APP: Dune Weaver is a remote control for a physical kinetic sand table running Dune Weaver Firmware. With a real table it communicates only over the local Wi-Fi network (direct HTTP to the device's firmware) — controlling the table needs no cloud service and no user account. Apart from the optional Pattern Hub below, the app stores all data locally on the device and transmits nothing off the local network.

If you connect to a real table instead of demo mode and the table is not on the same Wi-Fi, the control screens will show a "not connected" state — that is expected, not a bug. Please use demo mode for review.

PATTERN HUB (optional): The app controls a sand table people build from plans bought on duneweaver.com, and Pattern Hub patterns come with those plans. Nothing is sold in the app. Patterns only work on a Dune Weaver sand table, so access is unlocked for table owners without in-app purchase (guideline 3.1.4, hardware-specific content). Every pattern is reviewed and approved by Dune Weaver before it appears in the hub, and each one has Report this pattern in its details. To review it, go to Settings › duneweaver.com › Sign in and sign in with the demo account's email and password in the window that opens. That account owns a plan. Then open Browse, tap the Pattern Hub tab, pick a few patterns and tap Sync to table (the demo table takes them). Settings › duneweaver.com also has Delete account, which opens duneweaver.com/account/delete. Please don't delete the demo account: other reviews use it.
